# video_web_v3 架构说明

## 项目概述

video_web_v3 是一个基于 Go 语言构建的视频社交平台后端服务，采用微服务架构设计，支持实时聊天、视频分享、社交互动等核心功能。

## 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 语言 | Go | >= 1.26 |
| 框架 | Hertz | - |
| 数据库 | MySQL | 8.0+ |
| 缓存 | Redis | 7.0+ |
| 对象存储 | MinIO | - |
| RPC框架 | gRPC | - |
| 服务发现 | Consul | - |
| WebSocket | Gorilla WebSocket | - |

### 模块划分

| 模块 | 职责 | 关键功能 |
|------|------|----------|
| **api_gateway** | API 网关，处理 HTTP 请求转发 | 路由注册、JWT 认证、WebSocket 管理 |
| **app** | 后端应用服务，处理业务逻辑 | 用户管理、视频管理、社交互动、实时聊天 |

### 目录结构

```
video_web_v3/
├── api_gateway/           # API 网关
│   ├── biz/handler/       # HTTP 处理器
│   ├── client/            # gRPC 客户端
│   ├── idl/               # Proto 定义
│   ├── my_jwt/            # JWT 认证
│   └── router/            # 路由配置
└── app/                   # 后端应用
    ├── adapter/           # 适配器层
    │   ├── grpc/          # gRPC 服务实现
    │   ├── persistence/   # 数据持久化
    │   └── consul/        # 服务发现
    ├── domain/            # 领域层
    │   ├── model/         # 数据模型
    │   ├── repository/    # 仓储接口
    │   └── service_logic/ # 业务逻辑
    ├── usecase/           # 用例层
    └── idl/               # Proto 定义
```

## 核心功能

### 1. 用户服务
- 用户注册/登录
- 用户信息管理
- JWT 认证

### 2. 视频服务
- 视频上传/存储
- 视频播放
- 视频管理

### 3. 社交服务
- 关注/取消关注
- 粉丝列表
- 社交会话管理

### 4. 互动服务
- 点赞/取消点赞
- 评论管理
- 互动统计

### 5. 聊天服务
- WebSocket 实时通信
- 离线消息推送
- 消息持久化

## 数据流

### HTTP 请求流程

```
客户端 → API Gateway → gRPC Client → App Service → Repository → Database
                                                         ↓
客户端 ← API Gateway ← gRPC Client ← App Service ← UseCase ← Repository
```

### WebSocket 消息流程

```
客户端 ↔ WebSocket Handler ↔ gRPC Client ↔ App Service ↔ Database
```

## 关键设计

### 1. 认证机制
- 使用 JWT token 进行身份认证
- Token 存储在 Cookie 中
- 支持 Token 刷新机制

### 2. 实时通信
- 使用 WebSocket 实现实时聊天
- 心跳保活机制
- 离线消息存储与推送

### 3. 服务发现
- 使用 Consul 进行服务注册与发现
- 支持服务健康检查

### 4. 数据存储
- MySQL：存储结构化数据（用户、视频、消息等）
- Redis：缓存热点数据、会话管理
- MinIO：存储视频文件

## 安全性

- 密码加密存储（bcrypt）
- JWT Token 过期机制
- 输入参数校验
